Importing into Figma

  1. Run the html.to.design plugin in the target Figma file.
  2. Paste a URL from above, or the whole list if you're on a plan that takes multiple.
  3. Set the viewport to match the width above — the prototype is responsive, so a desktop viewport yields the desktop layout.
  4. For any state that only exists after interaction, use the browser extension to capture what's on screen instead.

Headless tooling can wait for html[data-capture-ready] or the capture:ready event rather than a fixed delay. Both fire once fonts and images have settled.
